# Web 面板设计规范

[文档首页](../README.md) · [仓库开发约定](../agents.md) · [测试与验收](TESTING.md)

面板的首要任务是让值班者快速回答「哪台主机离线了」。概览直接列出主机；历史趋势放在详情，配置和维护放在后台。视觉参照是一本账本：细线分区、等宽数字、纸与墨两套主题。空间不足时先删重复摘要，不隐藏主机状态。

## 颜色、文字与尺寸

实际颜色和字体栈集中在 [styles.css](../frontend/src/styles.css)。组件复用语义变量与 Tailwind utility，不各自硬编码主题颜色。

| 元素 | 规则 |
| --- | --- |
| 骨架与交互 | 背景、边框、文字、导航和筛选均用中性色。主按钮以墨纸反转强调，链接用下划线。语义色仅用于状态点、2px 校准线、状态词、错误和危险操作；图表数据色仅用于系列及其图例。 |
| 文字 | 站点名、页面 H1、空态标题可用衬线，字号不小于 20px；正文与控件用无衬线，数值、公钥、命令、时间戳用等宽字体和等宽数字。常用字号 11 / 12 / 14 / 16 / 20 / 28 / 40px。 |
| 布局 | 间距采用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px。内容最宽 1440px，桌面水平留白 24px、移动端 16px。主机卡片和图表独立排列、间隔 16px；详情事实带和后台列表用连续细线分隔。 |
| 控件 | 控件圆角 6px，容器 10px，不超过 12px。标准按钮高 32px（13px 字），行内按钮高 28px（11px 字），列表行至少 44px。每屏最多一个主操作；其他动作使用次按钮或文字。 |
| 质感 | 仅用细线、克制的微阴影和内联噪点纹理。不用渐变、装饰插图、图标库、外部字体、营销式卡片或抢占首屏的 KPI 数字。 |

## 页面与状态

- **概览与详情**：从主机列表直接进入详情。每台主机用不大于 8px 的状态点加文字；详情事实带列出 Agent 自报版本，缺失为「未知」。图表显示指标、时间范围、图例和离线区间，不把缺失采样画成零。
- **主机管理**：待注册记录用虚线框呈现一次性命令、过期时间和保密提示。创建或刷新后才能复制；过期隐藏复制入口，刷新页面不恢复明文。已绑定不显示凭据刷新。发布选择来自正式 release 列表，默认最新可安装版本；显式选择或清空后不自动覆盖。目标撤下时标记不可用，加载失败提供重试，不声称「已是最新」。安装与升级条件见[设备接入](AUTHENTICATION.md)。
- **维护任务**：状态同时使用点和文字，未知用警告而非失败样式。任务 ID、版本、时间与日志用等宽字体；日志块用弱对比背景，最大高度 320px。任务面板与详情间距 12px，标题 16px；下拉和操作按钮沿用 32px 高度。
- **路由与反馈**：概览保留首屏加载，详情和后台按需加载。加载中、空列表、请求失败、离线、未授权是不同状态。失败文案说明发生了什么、接下来能做什么，例如「主机列表加载失败。检查连接后重试。」面向用户的文案用中文；按钮用「保存设置」「复制命令」等动作词。

## 实现与无障碍验收

1. CSS 变量在 `:root` 与 `:root[data-theme="dark"]` 定义，经 `@theme inline` 映射。组件使用 utility；运行时计算的进度、尺寸可以用动态 style。图表从主题读取网格和刻度颜色，切换主题时更新；折线用线宽和图例辅助区分系列，关闭动画和平滑插值。
2. 正文对比度至少 4.5:1，大字号文字和必要的控件边界至少 3:1。焦点使用 2px 外环与 2px 间隔；切换主题后仍须可见。图表提供含指标和时间范围的可访问名称，状态与错误不能只靠颜色表达。
3. 用键盘遍历筛选、版本下拉、复制和对话框。对话框圈定焦点、支持 Escape 关闭并归还焦点；表单错误和保存结果通过 `aria-live` 通知。`prefers-reduced-motion` 下关闭脉冲与过渡。
4. 在窄屏、桌面、浅色和深色下检查长主机名、密集采样和错误态。以真实面板而非单张静态图验收，具体构建与检查顺序见[测试与验收](TESTING.md)。
